| 테스트 | 확인 내용 |
|---|---|

| 점검 항목 확인 처리 API | 확인 처리 후 `acked` |
| 데모 초기화 | 19건으로 복원 |
| 파일 저장소 영속성 | 서버 재시작 후 데이터 유지, 임시 파일 잔존 없음 |

## 7. 알려진 한계

- 로그인·권한이 없습니다(데모용 사용자 선택). 공개 API 외 모든 API가 인증 없이 열려 있으므로 **인터넷에 그대로 공개하면 안 됩니다.** 사업 기획서 10장 로드맵의 1순위입니다.
- 저장소는 단일 JSON 파일(원자적 쓰기)로, 동시 사용자가 많은 환경을 위한 것이 아닙니다.
- 문자·알림톡 발송, 전자세금계산서, 결제는 연동하지 않았습니다(링크 복사로 대체).
- E2E는 Chromium 엔진으로만 실행했습니다(휴대폰은 Pixel 7 에뮬레이션). iOS Safari 실기기 검증은 파일럿에서 진행합니다.
